## 4. 结论（逐项回答）

### 4.1 五块卵石（SS）人偶是否可见？

**可见，36 帧全部可见。** 尺度：橙色衣袍包围盒 **21–35 px 宽 × 24–47 px 高**，头部（粉白色小头，带两根粉色触须）约 **10 × 12 px**；头后有一圈带尖刺的深色光晕，直径约 **95–110 px**（14.00 s 起明显）。唯一不完整的是 17.00 / 17.50 s：人偶落到地面后下半身被底部 HUD 地面条带压住。

### 4.2 机械臂是否可见，整根还是部分？

**部分可见，本片没有一帧能干净看完整根臂。**

- 臂身（各节杆件、关节）在全部 36 帧可见。
- **底座板**：仅在 00.00–01.00 s（左墙 y≈175）与 06.00–15.50 s（顶边 x 392→188，板件在 y 28–55 清楚可见）可见；**01.50–05.50 s 底座在顶部右角，被房间角部倒角 + 右上角文字水印盖住，看不到板件**。
- **臂末端**：多数帧被头部/衣摆遮挡或被衣摆前沿切断；12.00–12.50 s 是唯一能同时看清"末端 + 可见空隙"的段落。

### 4.3 脐带 / 缆线（黑白相间主缆）是否可见？

**可见，全部 36 帧都能看到。** 表现为 **2 条并行的黑白虚线段**，实宽约 **4–6 px**（含两股与中间间隙），走向为弧线：

- 00.00–01.00 s：从人偶下摆向下、向左甩出弧再落到下边缘 x≈270。
- 02.00–05.50 s：从衣摆下垂成 U 形弧，落到下边缘 x≈350。
- 06.00–11.50 s：从臂的肘部附近下垂成深弧（最低点 y≈500），再落到下边缘 x≈310。
- 12.00–13.50 s：近乎垂直落到下边缘 x≈290。
- 14.00–17.50 s：转成沿臂下段并行、一路落到地面。

结论：**缆线存在且走向可读**；但"到底接在衣摆、臂末端还是臂中节"这一点**无法从该分辨率判定**（见 4.5）。

### 4.4 臂与衣袍的接合处：可见，还是被衣袍挡住？

**混合，属于"部分可见、精确接合点被挡住"。**

可测 / 不可测清单：

- **可测（误差 ±15%）**：臂各节长度比、臂总长 / 房间高度比、臂最大伸展时末端到轨道的水平距离、人偶在房间中的位置、底座沿顶边/左墙的像素坐标（±2 px）、关节数量（3 段杆 + 2 处主关节 + 末端 1 处）、每节夹角（±10–15°）。
- **可测但很粗（误差 ±20–40%）**：关节外径（4–6 px，±1–2 px 即 ±20–40%）、缆线直径（4–6 px，同量级）。
- **不可测**：枢轴盘是否有轴心孔/销钉/螺栓、关节内部结构、杆件倒角与材质、缆线股数/缠绕/打结、亚像素抖动、衣摆褶边、任何 < 2 px 的细节。
- **不能做的事**：拿本片反推真机像素尺寸或 UV 比例；把放大图的轮廓当作精确矢量化依据。

## 6. 时长/分辨率是否够用 —— 说明能测什么、不能测什么

- 片长 **18.12 s**，够短，且**不是一段连续动作**：24 fps 逐帧检测到 **4 处硬切点（1.500 / 6.083 / 11.875 / 13.792 s）**，人偶与底座在 1/24 s 内整体位移 105–329 px。**本片是 4–5 段静态姿势的剪辑拼接，没有"静置 → 移到侧边 → 停稳"的连续过程。**
- 分辨率 **720×720**，主体（人偶）仅占画面高度 **6–7%**，臂粗 6–10 px，关节 4–6 px，码率 141 kb/s（0.0113 bit/px）。**这是"看得见形状、量不出尺寸"的级别。**
- **可以拿它做的**：静态姿势参考（4 个姿势各自的比例与角度）、臂的节数与连接顺序、底座在轨道上覆盖的范围（顶边中段 + 两个角 + 左墙一段）、缆线的存在与大致走向、人偶与臂的相对位置关系。
- **不能拿它做的**：轨道滑动的时序与过角过程（本片没有）、关节几何（枢轴盘是否可见、销钉位置）、臂的动画曲线/缓动、缆线余量的动态变化规律、任何像素级或亚像素级的尺寸标定。
- **建议补录**：在游戏内录一段 30–60 s、1080p 以上、无水印、无鼠标指针、24 fps 以上、镜头固定不裁切的「静置 → 沿顶边移到侧边 → 停稳 → 快速拖拽 → 松手」连续动作；本片只能作为姿态底稿，不能作为动作参考。

## 7. QC 问题

1. **文字/水印遮挡**：右上角有「被原批吓疯」中文文字 + bilibili logo，覆盖 `x>440, y<60`。**01.50–05.50 s 恰好把机械臂的顶部右角与底座板挡住**，这一段无法判读底座形态。
2. **鼠标指针**固定在约 (660, 420)，全程画在画面上，遮住右中一小块背景。
3. **底部地面/HUD 条带**（y>620）压住人偶与缆线落点；17.00 / 17.50 s 人偶下半身被切掉，橙色掩码失效。
4. **二次压制**：Bilibili XCoder 重编码，141 kb/s / 0.0113 bit/px，高频细节基本损失，边缘 2–3 px 渐变，可见块状与蚊噪；关节、缆线这类 4–6 px 细节的边缘已经不可信。
5. **装饰细线干扰**：房间里有从人偶向外发散的细亮弧线（装饰须/光丝）横穿画面，与臂、缆线交叉处会误导边缘提取与骨架判定。
6. **运动欠采样**：本次按规则取 2 fps，0.5 s 内发生 216–329 px 的整体位移，过渡姿态几乎全部落在采样点之间；`frames_24fps/` 里的 3 段逐帧窗口就是为了核对这些过渡，结论是它们本身就是硬切，逐帧也看不到中间姿态。
7. **无音频轨**（对参考无影响，仅记录）。
